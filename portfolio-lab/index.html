Put it online for free github pages

Your whole site is one file called index.html. GitHub hosts it for free at username.github.io, so it stays online without anyone's computer running.

  1. Copy your website code.
    Copy is the quickest: you paste it straight into GitHub. Download saves the same code as a file called index.html, which you can upload instead.
  2. On GitHub, create a public repository named exactly your-username.github.io.
  3. In the new repo, click Add file → Create new file. Name it index.html, paste the code, then click Commit changes. (Downloaded the file instead? Use Add file → Upload files.)
  4. Wait about a minute and open https://your-username.github.io. If it doesn't appear, go to Settings → Pages, choose Deploy from a branch → main / root and save.
  5. To update later: change things here, copy again, open index.html on GitHub, click the pencil, replace everything and commit.
